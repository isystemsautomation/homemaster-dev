# Partner kit changelog

## 2026.09.1 — 2026-09-25

- All datasheets re-issued as Rev. B; specification tables generated from one source per module (identical in datasheet, README, product page and specs.csv).
- Enclosure dimensions unified (height 90.6 mm, depth 67.3 mm); one dimensional drawing set for all modules.
- OpenTherm Gateway and MiniPLC: supply 24 V DC or 85–265 V AC only; 120–370 V DC removed.
- Relay outputs: 3 A @ 250 VAC module limit on all modules; component ratings removed.
- Catalogue and user manuals aligned with Rev. B datasheets.
