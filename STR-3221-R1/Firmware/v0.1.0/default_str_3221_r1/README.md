# `default_str_3221_r1` — Arduino sketch (v0.1.0)

Main firmware for **STR-3221-R1** (RP2350): Modbus RTU slave, 32 TLC59208F output channels, 3 isolated inputs, 4 buttons, 2 status LEDs, and unified WebConfig over USB.

Build with Arduino IDE or `arduino-cli` using the **RP2350** board profile (same toolchain as other HomeMaster RP2350 modules).
